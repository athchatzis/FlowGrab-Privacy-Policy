# FlowGrab Privacy Policy

Last updated: October 3, 2026

FlowGrab detects and downloads supported video and audio from web pages. Media assembly and conversion take place locally inside Chrome.

# Information processed

FlowGrab processes page and media URLs, media titles and captions, thumbnails, player metadata, playback and selection signals, media-related network information, manifests, subtitles and downloaded media. This information is used to identify the relevant video, display previews and quality options, and perform downloads.

When a preview is unavailable, FlowGrab may temporarily capture the visible tab and crop the capture to the video area. Preview processing takes place locally.

# Storage and retention

Preferences and a limited download history, including titles and source URLs, are stored locally in the browser. Detected media information is kept in browser session storage and removed when its tab is closed or the browser session ends.

Completed download records can be removed using FlowGrab’s Clear download history control. Uninstalling FlowGrab removes its extension storage. Downloaded files and Chrome’s own download history are managed separately by the user.

# Network requests and sharing

FlowGrab requests media and metadata from the original websites and their media providers. Chrome may use the existing website session for these requests. FlowGrab does not read passwords or export authentication cookies.

FlowGrab does not send browsing data, previews, download history or downloaded media to the developer. It has no analytics or advertising trackers and does not sell user data.

# Limited Use

FlowGrab uses information only to provide its media detection, preview and download features. Its use of information complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.
